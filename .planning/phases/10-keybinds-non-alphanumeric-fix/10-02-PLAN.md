Point GoofCord at the fixed venbind so the named-key tokens from plan 10-01 actually match at
runtime. Today `package.json` pins `"venbind": "0.1.7"` (broken upstream npm). The fixed
vocabulary lives in the `thomas-quant/venbind` fork (branch `fork-ci`, CI-green, run 27314521855,
artifacts `venbind-windows-x86_64.node` + `venbind-linux-x86_64.node`).

`GOOFCORD_VENBIND_PATH` env override — so NO build.ts change is needed. Only the dependency
SOURCE changes. Because that switches the dependency source, commits/relocates binaries, and may
churn `bun.lock`, it is a USER DECISION — this plan is gated and MUST NOT run unprompted.
</objective>
