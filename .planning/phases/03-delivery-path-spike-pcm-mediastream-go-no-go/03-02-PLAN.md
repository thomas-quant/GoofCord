<objective>
Build the spike's renderer-side logic in a PACKAGED location and inject it into the Discord page's main world behind the `GOOFCORD_DELIVERY_SPIKE` gate. This is the make-or-break of the whole spike: it proves a non-Discord audio track reconstructed in the renderer can be swapped into `getDisplayMedia`'s MediaStream and reach a remote viewer (SC#1), records which reconstruction mechanism works (SC#2), and writes the reachability + corroboration signals to `screenshare-debug.log`.

Purpose: GoofCord's `postVencord.js` is DOWNLOADED from upstream `main` at runtime (settingsSchema.ts:217) and is NOT in the packaged artifact — spike code placed only there would silently not ship and the spike would test nothing (RESEARCH §Pitfall 1). The spike code therefore lives in the main preload bundle (`ts-out/**`, which electron-builder DOES package per electron-builder.ts:5) and is injected to the page main world via `webFrame.executeJavaScript`, exactly as `assets.ts:loadScripts()` already injects downloaded scripts.
Output: `src/windows/main/preload/deliverySpike.ts` (new, packaged) + a gated call from `preload.mts`.

Consumes Plan 01's interface: `window.goofcord.deliverySpike` (gate bool) and `window.goofcord.appendScreenshareDebug(line)`.
</objective>
